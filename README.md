## Overview

CJB Cheats Menu is one of the oldest and most comprehensive SMAPI mods for Stardew Valley, providing a hotkey-activated in-game menu with cheats for time speed control, instant crop growth, weather change, money addition, relationship maxing, warp to any location, and dozens more quality-of-life shortcuts. It is fully compatible with all Stardew Valley content updates.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **CJB Cheats Menu** delivers the features you need in a clean, intuitive package.
